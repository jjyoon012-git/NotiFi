# 2026.06.26 NotiFi CSI-to-Pose Experiment Log

## Summary

CSI-to-Pose experiment planning was added to the NotiFi repository.

The experiment is based on a teacher-student structure:

```text
Training:
CSI + Video
→ Video Pose Teacher
→ Skeleton GT / Derived Features
→ CSI Student Model

Inference:
CSI only
→ 3D Skeleton Proxy
→ Behavior / Event Interpretation
```

## Experiment Direction

The experiment does not aim to reconstruct real video frames from CSI.
Instead, it aims to predict a compact 3D skeleton proxy from CSI signals.

The first skeleton representation is a 13-point proxy:

```text
head
left_shoulder, right_shoulder
left_elbow, right_elbow
left_wrist, right_wrist
left_hip, right_hip
left_knee, right_knee
left_ankle, right_ankle
```

Derived features include:

- `body_center`
- `shoulder_center`
- `hip_center`
- `body_height`
- `torso_angle`
- `motion_velocity`
- `height_velocity`
- `wrist_motion`
- `ankle_motion`

## Pilot Plan

Before collecting the full CSI-to-Pose dataset, the first pilot will use:

```text
risk: warning
domain: gait
detail_label: unstable_walking
duration: 20s
```

The pilot goal is to verify:

- MediaPipe landmark extraction
- 13-point skeleton proxy generation
- derived feature extraction
- CSI/video trial matching
- initial CSI-to-skeleton proxy feasibility
