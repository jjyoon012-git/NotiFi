## 사용한 주요 코드

`NotiFi-Data`에 업로드한 주요 코드:

| script | role |
|---|---|
| `scripts/save_csi_raw.py` | receiver 시리얼에서 `CSI_DATA`만 CSV로 저장 |
| `scripts/team3_collect.py` | Team 3 라벨/ambient 계획에 맞춰 반복 수집, 알림음, 이미지 저장 |
| `scripts/augment_post_fall_from_fall.py` | 낙상 10초 데이터를 낙상 후 무활동 20초 데이터로 증강 |
| `scripts/augment_warning_music_from_tv.py` | TV 기반 warning music synthetic 데이터 생성 |
| `scripts/augment_warning_quiet_from_collected.py` | aircon/TV 기반 warning quiet synthetic 데이터 생성 |

## Synthetic Data 주의

다음 데이터는 직접 수집이 아니라 개수 보정 및 실험 진행을 위해 증강했다.

- `post_bed_fall_inactive`
- `post_chair_fall_inactive`
- 일부 warning ambient 데이터
- 일부 warning quiet/music 데이터

증강 이력은 `NotiFi-Data/yja/collection_logs/`에 CSV 로그로 남겼다.

모델 학습/평가 때는 direct 데이터와 synthetic 데이터를 구분해서 보는 것이 좋다.

## 수정한 이상치

문제 파일:

```text
data/warning/gait/unstable_walking/yja/yja_unstable_walking_t002.csv
```

문제:

```text
20초 수집이어야 하는데 실제 길이가 약 3.6초였다.
```

처리:

```text
t001 앞 절반 + t003 뒤 절반을 합쳐 t002를 재생성했다.
timestamp는 약 19.986초 범위로 다시 보정했다.
```

재검산:

```text
unstable_walking 전체 66개
row 범위 1732~1873
짧게 끊긴 파일 없음
```
