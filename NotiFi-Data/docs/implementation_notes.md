# v2.0 구현 기준 메모

첨부 계획서와 3TX+1RX 업데이트 가이드 사이에 남아 있는 이전 문구는 다음 기준으로 정리했다.

- 라벨의 단일 기준은 계획서 2.1의 17개 라벨 표다.
- 삭제 대상으로 표시된 `W04`와 `chair_sit_miss_recover` 참조는 코드, 설정, 팀원 문서에 포함하지 않았다.
- 1인·1환경은 275회, 1인·3환경은 825회, 4인 전체는 3,300회다. 계획서 후반의 1인 900회와 전체 3,600회 문구는 이전 수치로 판단해 적용하지 않았다.
- 3TX 송신률은 최신 3TX+1RX 가이드의 `30 pkt/s`를 적용했다. 계획서 15장의 100 pkt/s 파일럿 문구보다 최신 가이드를 우선했다.
- 기존 배경 조건별 분기는 제거했다. core 수집은 배경 조건을 나누는 CLI 인자나 하위 라벨을 만들지 않는다.
- 모든 원본 trial은 10초로 고정했다.
- `post_fall_inactive`는 독립 라벨로 만들지 않고 낙상 후 post-event state 분석 대상으로 남긴다.
- `absence`는 classification/occupancy에는 사용하지만 pose reconstruction에서는 제외한다.
